This is a simple IOT application using ESP-32 based HTTP web server and client.

*** espclient: Reads onboard temperature and HALL sensor data and then uploads to the ThingSpeak server.
*** espserver: Reads onboard temperature and HALL sensor data and then creates a local HTTP web server from 
	       where data can be refreshed every time to read new sensor readings.

Hardware Connection:
ESP32 GPIO 13 --> LED Anode
